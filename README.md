# Mi App Usuarios — Ejemplo Práctico

Aplicación móvil desarrollada con **React Native + Expo** que consume la API REST de **JSONPlaceholder** mediante **Axios**, con dos pantallas (lista y detalle).

## 📋 Requisitos previos

- Node.js 18 o superior
- npm 9 o superior
- Git (opcional, para clonar)

## 🚀 Instalación paso a paso

### 1. Clonar el repositorio

```bash
git clone https://github.com/TU-USUARIO/mi-app-usuarios.git
cd mi-app-usuarios
